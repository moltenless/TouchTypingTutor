# ⌨️ TouchTypingTutor - Multilingual Typing Trainer

**Master touch typing in English or Russian! Train with customizable lessons, get instant visual feedback, and track your typing speed and accuracy with detailed stats.**

---

## 🧠 What It Does

- 🌐 **Language Support**: Choose between English or Russian typing lessons.
- ✍️ **Custom Lesson Length**: Enter how many characters you want to type.
- 📝 **Flexible Content**:
  - Reads typing content from editable `.txt` files for each language.
  - Automatically falls back to built-in default text if files are missing or broken.
- 🎯 **Typing Practice**:
  - Type the shown text symbol-by-symbol.
  - Correct keys are marked in **green**, mistakes in **red**.
- 📊 **Session Statistics**:
  - Total characters typed
  - Mistake count
  - Typing speed (symbols per minute)
